Side Projects

📄️Manage GitHub Org Permissions - GitHub Action

GitHub Action on the GitHub Marketplace that manages a GitHub organization's teams, repository permissions, and collaborators from one YAML file, so every access change goes through a reviewed pull request.

📄️Release Helm Charts - GitHub Action

GitHub Action on the GitHub Marketplace that publishes Helm charts to GitHub Pages. One step finds changed charts, lints and packages them, and updates the chart repository index without dropping older versions.

📄️Horizon Social Network - Microservices Backend

A Go backend for a campus social network, built for a university workshop project. Two microservices on Kubernetes behind the Istio service mesh, with Keycloak login tokens checked at the entry gateway, mTLS between services, MongoDB for posts, Neo4j for the follower graph, and container images under 10MB.

📄️Box2Home - Internal Data Platform

Internal web app I built during my 2023 internship at Box2Home so developers could debug with production data. It replaced a paid third-party tool, with read-only, role-based access to 100+ production tables and a log of every query.
