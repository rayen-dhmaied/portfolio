Work Projects

📄️DeployCenter - Multi-Tenant Kubernetes Deployment Platform

Deployment platform I built for 20+ customer apps across 3 AWS regions. It cut per-app deploy time from 15 minutes to 3. I make batch changes from Git, developers deploy from a web dashboard, and both paths run the same Python orchestrator.

📄️Kubernetes Observability Stack

Monitoring and alerting stack I built for production Kubernetes on AWS EKS. It cut mean time to resolve incidents (MTTR) by 50%, log storage cost by 70%, and alert volume by 60%, with Prometheus, Loki, Grafana OnCall, and external HTTPS probes.

📄️Scalable BigBlueButton on AWS

A video conferencing platform I designed and built on AWS at CraftSchoolship, running the open-source BigBlueButton software as an auto-scaling fleet. A custom machine image cut server launch time from 11 minutes to 3, and scale-in protection keeps live meetings running while the fleet shrinks.

📄️QuizShip - Live Interactive Quiz Platform

Live multiplayer quiz SaaS built as a Go game server and a Python API with a React frontend, Stripe subscriptions, and GitOps deploys on Kubernetes. Load-tested to 30,000 concurrent players on two game pods with zero errors.

📄️HR System Hub - Serverless HR Platform for Manufacturing

HR platform that replaced a manufacturing client's paper employee evaluations. Lead contributor on a three-engineer contract team. Serverless on Firebase in EU regions, about 120 API endpoints, and 1,400+ tests.
